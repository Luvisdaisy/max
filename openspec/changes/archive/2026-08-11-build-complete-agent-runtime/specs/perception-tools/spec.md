## MODIFIED Requirements

### Requirement: 内存屏幕观察
系统 SHALL 提供 `observe_screen`，用于捕获全虚拟桌面或调用方指定显示器的当前图像，并返回任务级内存图像引用、物理像素尺寸、显示器边界、可用 DPI 元数据、捕获时间和当前前台窗口摘要。图像引用 MUST 仅在所属任务生命周期内可解析；该工具 MUST 不默认写入截图文件，且 MUST 不发送鼠标或键盘输入。

#### Scenario: 捕获指定显示器
- **WHEN** 调用方请求一个可用显示器的截图
- **THEN** 系统在任务内存中保存图像并返回可供后续感知和规划工具使用的引用及对应物理像素元数据

#### Scenario: 跨任务使用图像引用
- **WHEN** 工具请求解析属于其他任务、已释放或不存在的图像引用
- **THEN** 系统返回明确失败回执，且不读取磁盘、重新捕获屏幕或访问其他任务内存

#### Scenario: 显示器不可用
- **WHEN** 调用方请求不存在或不可捕获的显示器
- **THEN** 系统返回失败回执，且不产生截图文件或桌面输入

### Requirement: 结构化文字识别
系统 SHALL 提供 `recognize_text`，用于识别当前任务内存图像引用指向的完整图像或指定变化区域，并返回文本行、置信度和图像物理像素坐标边界框。Agent 的屏幕文字理解 SHALL 默认采用截图后 OCR 主路径；该工具 MUST 不自行捕获屏幕、不保存输入图像，并且 MUST 在本地 OCR 资源不可用时返回明确失败回执而不下载资源。

#### Scenario: 识别内存图像中的文字
- **WHEN** 当前任务首次获得包含可识别文字的屏幕图像且本地 OCR 资源可用
- **THEN** 编排器可将图像引用交给 OCR，并获得与该截图坐标一致的结构化文字元素

#### Scenario: 对变化区域执行 OCR
- **WHEN** 后续截图仅有已知局部区域发生变化
- **THEN** OCR 可只识别指定区域并把结果坐标转换回原屏幕图像坐标，未变化区域可复用同一任务中的有效结果

#### Scenario: 本地 OCR 资源缺失
- **WHEN** 调用方请求文字识别而本地 OCR 资源不可用
- **THEN** 系统返回说明资源不可用的失败回执，且不发起网络访问或资源下载

### Requirement: UI 与视觉观察增强
系统 SHALL 提供只读的顶层窗口发现、UI Automation 元素观察、图像预处理、模板匹配和按需 Set-of-Mark 标注能力。窗口发现 SHALL 返回任务栏可见性、前台状态以及窗口句柄、进程标识和已解析可执行路径；UIA SHALL 仅辅助窗口身份、焦点、元素属性和 OCR 不可用场景。视觉处理和标注 MUST 仅处理当前任务的内存图像引用，且所有这些工具 MUST 不发送桌面输入或默认持久化图像与完整文本。

#### Scenario: 发现任务栏可见窗口
- **WHEN** 编排器请求当前桌面顶层窗口摘要
- **THEN** 系统返回可见窗口的稳定身份、边界、前台状态和任务栏可见性，不激活或操控任何窗口

#### Scenario: 返回可访问窗口的 UI 元素
- **WHEN** 编排器对一个已识别目标窗口请求 UI Automation 观察
- **THEN** 系统返回元素角色、名称、边界、焦点和可用状态，并在可用时提供受限 Text/Value 证据

#### Scenario: 处理视觉输入
- **WHEN** 调用方以当前任务图像引用请求预处理、模板匹配或 Set-of-Mark 标注
- **THEN** 系统返回新的内存资源引用及相应坐标或标记元数据，且不写入图像文件

#### Scenario: UI Automation 目标不可访问
- **WHEN** 调用方请求不存在、无权限或无法连接的窗口
- **THEN** 系统返回失败回执，并允许编排器继续使用截图与 OCR 观察，但不尝试激活窗口或发送桌面输入

## ADDED Requirements

### Requirement: 统一观察与状态指纹
系统 SHALL 将同一捕获时刻的屏幕元数据、窗口摘要、OCR 元素和可选视觉结果组合成标准化观察，并 SHALL 计算可比较的状态指纹和相对上一帧的变化区域。组合观察 MUST 保留每项证据的来源和对应图像引用。

#### Scenario: 形成首帧标准化观察
- **WHEN** 截图和主要 OCR 调用成功
- **THEN** 系统生成包含屏幕、窗口、文字元素、状态指纹和来源信息的标准化观察供模型规划

#### Scenario: 识别无进展画面
- **WHEN** 相邻观察的前台窗口、关键 OCR 元素和感知哈希基本相同且变化区域低于阈值
- **THEN** 系统输出可由验证与恢复策略消费的无进展证据，而不自行重试或发送输入
