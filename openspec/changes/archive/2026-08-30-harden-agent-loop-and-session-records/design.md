## Context

现有图已经具备 Think → Act → Observe 拓扑、视图坐标边界校验、工具执行事件和
`task_complete` 门槛。实际会话显示，工具错误只作为自然语言回注给模型，缺少对同类错误的
结构化计数与恢复指令；`task_complete` 又在 Act 内立即设置验证状态。会话顶层 `messages`
与 `checkpoint.messages` 重复保存同一运行消息，运行 JSONL 的汇总没有投影到会话文件。

实现必须保持本地 JSON/JSONL、旧会话可读和已有单副作用工具批次限制，不新增网络服务、
数据库或模型专用分支。

## Goals / Non-Goals

**Goals:**

- 让坐标越界、重复空定位和重复失败在有限次数后改变可用工具与模型上下文，而非无限重试。
- 让完成声明只能发起验证，只有独立后置观察满足声明证据时才能进入 `done`。
- 让新会话仅保存一份消息历史，并用小型 checkpoint 与运行摘要支持恢复和离线诊断。

**Non-Goals:**

- 不改变截图缩放、`ViewFrame` 到逻辑坐标的换算公式，也不引入 OCR/视觉模型替换。
- 不保证模型能识别任意 Dock 图标；护栏只限制无效循环并提供可观察的降级路径。
- 不迁移、压缩或重写已有会话、截图和运行日志。

## Decisions

### 在任务上下文中保存有界恢复信号

`TaskContext` 增加当前任务的恢复信号：最近失败指纹、连续次数、已禁用的重复查询和一次性
恢复建议。`observe` 根据结构化 `exec.code` 与规范化参数更新它，`think` 将建议注入契约并
从允许工具中移除被暂时禁止的重复调用。坐标越界必须要求新的 `screenshot` 或当前帧的
`target_id`；同一语义 locate 连续未命中后必须要求空查询/不同观察方式，且每种恢复动作有
固定上限。

选择在上下文中维护而不单独增加 LangGraph 节点：状态仍保持三节点拓扑，恢复原因可随
checkpoint 保存。仅依靠提示词不能保证模型从工具错误中切换策略；全局熔断又会错误阻断不同
子任务。

### 将完成声明与验证拆开

`task_complete` 只记录候选 summary/evidence 和其声明前的最新观察帧，不设置
`completion_verified`。随后图必须产生新的 `screenshot`，由确定性校验器检查该截图属于
声明之后、可读取、且存在与声明一致的可验证事实或明确的验证失败。只有通过才置 `done`；
失败则回到 `think`，模型看到失败原因。

选择确定性验证器而非让下一次模型文字确认：模型不能成为自身完成证据的唯一裁判。首版只
验证时间顺序、图像存在性与结构化事实绑定；无法稳定识别的视觉业务事实必须报告“证据不足”，
而非猜测成功。

### 顶层消息为唯一事实源

新 checkpoint 使用 `message_cursor` 指向已纳入图状态的顶层消息，并保存运行身份、迭代、
待调用、计划、任务上下文和恢复/完成状态；不得包含 `messages`。恢复时 Store 从顶层消息按
游标重建图状态。会话在顶层增加 `run_summary`，记录终态原因、计数、耗时、结束原因和已知
token 汇总；大型 locate 输出在工具消息中保留摘要、帧引用和候选数，详细框数据只留在按帧
观察文件中。

选择游标而非内容哈希：消息只追加且已有稳定顺序，游标可直接验证范围并降低恢复成本。保留
原始 reasoning 于唯一消息记录，便于调试；不在 checkpoint 或运行摘要中复制它。

### 向后兼容采用读取时降级

加载旧 checkpoint 的 `messages` 时，仅在顶层消息不足以恢复的旧文件中使用其作为兼容输入；
下一次保存改写成游标格式。旧文件缺 `run_summary`、观察引用或恢复信号时使用空值。不会批量
写回历史文件。

## Risks / Trade-offs

- [护栏过严阻塞合法重试] → 仅按相同错误码、规范化参数和当前帧计数；新截图或新子任务会清零。
- [完成校验无法理解复杂视觉结果] → 明确返回证据不足并继续 Agent，而不是错误标记完成。
- [checkpoint 游标与消息损坏不一致] → 加载时验证范围，越界则降级为最近完整顶层消息并标记不可恢复。
- [观察明细外置后调试不便] → 保留帧 ID、文件路径、摘要和候选数，并让详细观察文件可按引用定位。

## Migration Plan

1. 先增加状态/序列化兼容层与单元测试，不改变旧文件。
2. 接入恢复护栏与完成验证，使用模拟工具与固定截图验证状态迁移。
3. 将新会话写入游标 checkpoint、观察引用和运行摘要；保留旧 checkpoint 读取分支。
4. 若新格式出现恢复问题，停止写入新字段并使用顶层消息重建；既有 JSON 不需要回滚或删除。

## Open Questions

  工具可稳定提供的事实为准，不能把模型自然语言判断当作校验器。
