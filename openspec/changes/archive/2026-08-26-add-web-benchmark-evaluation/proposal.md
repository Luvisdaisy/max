## Why

项目已具备工具契约、ReAct 状态机和单步 LoRA 动作格式评估，但尚不能以可复现的方式
衡量 Agent 在完整 GUI 任务中的完成能力。真实桌面应用受账号、网络、窗口状态和个人数据
影响，无法作为基础模型与 LoRA 模型的稳定对照环境；因此需要一个仅在本机运行的受控 Web
测试场和自动化任务级评测流程。

## What Changes

- 新增仅监听本机回环地址的 Python Web 测试场，提供表单、文件列表和设置等可视 GUI 页面。
- 定义不少于 100 条分级任务，覆盖点击、输入、滚动、多步骤操作、错误提示、确认弹窗和恢复。
- 为每条任务定义可重置初始状态、自然语言指令、成功断言、禁止动作、工具调用上限与超时。
- 新增评测运行器：重置测试场、在固定浏览器环境中运行 Agent、读取独立业务状态并生成结果。
- 复用现有运行 JSONL 汇总任务成功率、耗时、工具调用、工具失败和已知 Token 用量，并支持以
  完全相同的任务配置对比基础模型与 LoRA 模型。

## Capabilities

### New Capabilities

- `web-gui-benchmark`: 提供只使用 Python 实现、可重置且可由真实浏览器键鼠操作的本地 GUI 测试场。
- `agent-task-evaluation`: 以任务定义驱动 Agent 闭环执行、独立状态断言和可审计指标报告。

### Modified Capabilities

<!-- 无。现有桌面工具与运行可观测性协议保持不变，评测能力通过新增模块消费其公开结果。 -->

## Impact

- 新增 Python Web 依赖、`src/max_gui/benchmark/`、任务定义与静态页面资源。
- 新增 `scripts/eval_agent.py` 及对应测试，复用 `AgentRunner`、桌面工具和运行事件。
- 在 `artifacts/` 下生成可忽略的评测报告与运行证据；不接入外网、DOM 自动化、真实账号或个人数据。
