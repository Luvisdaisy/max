# web-gui-benchmark Specification

## Purpose

提供仅限本机、由真实浏览器经普通键鼠操作的可重置 Web GUI 测试场，用于安全验证 Agent 的可见界面交互能力。
## Requirements
### Requirement: 本地受控 Web 测试场

系统 SHALL 提供仅绑定回环地址的 Vue + Vite Web 测试场，由单个 Python FastAPI 进程托管构建产物与
本地接口。页面 MUST 由真实浏览器渲染并接受普通鼠标、键盘和滚轮操作；服务 MUST NOT 访问外网、
真实账号、个人文件或消息服务。

#### Scenario: 浏览器展示 Vue 业务页面

- **WHEN** 评测运行器启动测试场并打开指定 v2 任务路由
- **THEN** 浏览器显示可完成业务操作并呈现结果的 Vue 页面，且服务只监听 `127.0.0.1`

### Requirement: 任务初始状态可重置

测试场 SHALL 为每个已注册的 v2 任务保存独立的后端业务初始状态。评测运行器调用本机重置接口时，
服务 MUST 恢复任务指定的路由、表单值、列表内容、对话框、分页或滚动相关状态；前一次运行产生的
数据 MUST 不影响下一次运行，且 Vue 页面 MUST 在重置后呈现该状态。

#### Scenario: 同一任务连续两次运行

- **WHEN** 任务在第一次运行中修改了业务数据，随后运行器再次重置同一任务
- **THEN** 第二次运行开始时 Vue 页面和评分状态均恢复为任务初始状态，不含第一次运行的修改

### Requirement: 业务状态仅供评测器读取

测试场 SHALL 通过仅限本机的状态接口返回完成评分所需的最小后端业务状态。该状态接口及重置接口
MUST 不在 Vue 任务页面中展示、链接或通过 Agent 工具暴露；页面和业务 API 也 MUST NOT 直接显示
任务答案或成功断言。

#### Scenario: Agent 只能经 GUI 完成任务

- **WHEN** Agent 执行一条本地 Web 任务
- **THEN** Agent 仅通过现有截图和桌面键鼠工具与浏览器页面交互，评分状态仅由评测运行器读取

### Requirement: 可见交互覆盖基准任务类型

测试场 MUST 提供与 v2 能力标签对应的可见交互，至少覆盖点击、文本输入、选择、筛选、排序、滚动或
分页、编辑、批量操作、多步骤保存、表单校验、确认流程、动态反馈和布局变化。用户动作成功或失败后，
Vue 页面 MUST 呈现与后端业务状态一致的后续界面。

#### Scenario: 校验错误后修正并保存

- **WHEN** Agent 在必填表单未填完整时提交，随后补全字段并再次提交
- **THEN** Vue 页面先显示可见校验错误，后显示保存后的业务结果，状态接口反映最终保存值

### Requirement: 业务关系与反馈的独立评分

测试场 SHALL 在评分状态中保存任务实际读取的业务事实、实体最终值和必要反馈检查点。评分器 MUST 只在
这些状态与任务断言全部一致时判定严格成功，且不得仅以页面访问或最终文本代替事实依赖。

#### Scenario: 读取事实但执行错误操作

- **WHEN** Agent 已访问报表并记录可见事实，但将任务更新为不符合该事实的目标值
- **THEN** 任务不通过严格评分，报告保留已满足的事实检查点与未满足的实体断言

### Requirement: 环境失败按题隔离

测试场与运行器 SHALL 将浏览器启动、页面可观察或状态读取失败归类为当前任务的 `environment_error`，继续
执行剩余任务并写入已有结果。环境错误 MUST 不计入模型任务失败率。

#### Scenario: 单题浏览器环境不可用

- **WHEN** 某题的专用浏览器 profile 无法启动或目标页无法观察
- **THEN** 当前题写入 `environment_error`，批次继续，报告分别统计计划题、已执行题与环境错误题
