## ADDED Requirements

### Requirement: 记录推理上下文裁剪诊断
每次模型调用的运行事件 MUST 记录不含敏感正文的上下文诊断：任务标识、发送消息数、内联图片数、近期
动作数，以及从模型请求排除的历史消息数。已知 token 用量继续按现有规则记录与累计；用量未知时 MUST
省略或标为未知，MUST NOT 伪造为 0。诊断 MUST NOT 复制用户指令、助手正文、截图路径或字节、OCR 全文、
键盘输入正文、密钥或 Authorization Header。

#### Scenario: 已裁剪请求可观测
- **WHEN** 新任务发起模型调用且同一会话含历史任务消息
- **THEN** 对应模型事件含发送消息数和排除历史消息数，且不含历史消息正文

#### Scenario: 未知用量不伪造零
- **WHEN** 一次经裁剪的模型调用未回传 usage
- **THEN** 其事件和运行汇总不以 0 表示该调用的 token 用量
