## Context

现有 `TaskContext` 只保留计划、最新观察和六条动作摘要。虽然当前任务最近六个完整工具调用链会再次发送给模型，且 `locate_hits` 可随会话恢复，但这些机制没有把“目标标签—编号—来源截图—可执行状态”收敛成模型易用、可校验的事实。`screenshot` 会更新 `ViewFrame` 并清空定位表，这是避免旧截图坐标误点的既有安全边界，不能因记忆复用而放宽。

## Goals / Non-Goals

**Goals:**

- 在单个任务内保存有限、脱敏、可恢复的 GUI 事实，减少同一有效画面中的重复 `locate`。
- 只让模型看到与当前截图一致的定位句柄，并在移动后的截图中明确下一步点击条件。
- 与现有 `think → act → observe → think`、JSON 会话和 `target_id` 坐标安全约束兼容。
- 让旧 session/checkpoint 缺少新字段时安全降级。

**Non-Goals:**

- 不实现跨任务、跨会话或长期知识记忆，不引入向量库、数据库或外部服务。
- 不把截图坐标、OCR 全文、键盘输入正文或全部原始工具输出复制进事实记忆。
- 不允许模型跳过“移动后截图核验、无坐标点击”的闭环，也不让历史图片的定位结果可执行。

## Decisions

### 使用任务胶囊中的结构化事实，而非保存全部工具输出

在 `TaskContext` 新增有上限的 `grounded_facts`。每条事实包含种类、短标签、状态、来源截图标识和简短结论；定位事实额外包含仅供模型调用的 `target_id`，不保存逻辑中心。工具原文仍只存在会话消息中，近期链仍按原策略发送。

选择这一方案是因为原始工具结果可能携带路径、OCR 或长文本，直接累积会增加上下文并放大敏感信息。仅靠现有六条调用链则会在长任务中丢失可复用语义。

备选方案是把所有工具 JSON 永久拼进提示词；因上下文增长和陈旧坐标风险被否决。

### 以当前 ViewFrame 的截图路径作为事实有效性边界

定位事实只能由 `coordinate_space=view` 且 `observation_only=false` 的 `locate` 结果创建，并记录当时活动 `ViewFrame.image_path`。成功生成新截图时，所有绑定旧路径的定位事实必须失效并从模型摘要移除，与 `locate_hits` 清空同步。历史图片、带框副本、解析失败和空结果不得创建或保留可执行定位事实。

选择路径身份而非图像相似度或坐标阈值，沿用现有“绝对路径等于活动帧”的安全契约。图像内容相同并不代表坐标系或桌面状态相同。

### 将“目标已移入并核验”与“定位编号可用”分离

成功以有效 `target_id` 执行 `mouse_move` 后，后置截图建立一个短期的光标核验事实：目标标签、来源截图与“可调用无坐标 `mouse_click`”结论。定位事实随新截图失效，但该核验事实代表后置截图的观察结果，可保留到下一次破坏性动作、失败或新的移动改变其含义为止。事实只能提示下一步；最终是否允许点击仍由现有桌面工具门禁决定。

这样既避免模型在移动与点击之间再次定位，又不把旧坐标视为可执行。备选方案是移动后保留原定位编号；它会让旧帧编号在新帧中复活，因此不采用。

### 以受限事实摘要补充现有模型上下文

`task_context_message` 增加一个固定长度的“当前有效事实”段：只列出有效定位的标签与 `target_id`，或最近的光标核验及允许的下一步。摘要按事实状态过滤、去重并限制条数和总字符数；不得包含失效事实、逻辑坐标、键盘正文或 OCR 正文。系统提示同步说明：已有当前帧有效定位时优先使用它；没有有效定位时才调用 `locate`。

这与近期完整工具链互补：后者保留短期证据，前者在调用链裁剪后仍保留最小决策信息。

## Risks / Trade-offs

- [工具标签含糊或重复] → 将事实视为模型提示而非执行授权；执行仍以 `target_id`、当前帧与桌面门禁校验。
- [事实更新遗漏导致陈旧提示] → 所有成功截图统一触发失效；对 locate、move、点击/拖拽/滚动/键盘、错误和中断分别覆盖测试。
- [摘要过长反而挤占上下文] → 对事实条数、单条文本和总字符数设硬上限，并保留既有六条调用链上限。
- [旧会话无法恢复] → `grounded_facts` 缺失或格式不合法时使用空列表；不从历史消息反向猜测可执行编号。

## Migration Plan

1. 为新任务胶囊和恢复逻辑加入可选事实字段，并保持旧 JSON 可读。
2. 在工具结果进入 `act` 时提取受信任事实；在截图与动作边界更新或失效。
3. 在模型上下文与系统契约中使用事实摘要，补充单元和回归测试。
4. 若需回滚，停止写入和注入 `grounded_facts` 即可；旧会话中的未知字段会被忽略，不需要数据迁移。

## Open Questions

- 首版事实上限建议为 6 条、摘要总长 600 字符；实现时可依据实际 token 观测微调，但不得取消硬上限。
- 第一版仅从 `locate` 和 `mouse_move` 生成面向点击的事实；是否在后续变更中把 OCR 识别出的非敏感控件名称纳入同一机制，待真实任务数据验证后再决定。
