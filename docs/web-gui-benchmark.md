# Web GUI Agent 评测场

`web-gui-v1` 由 20 个工作流模板各展开 5 次，共 100 条任务。页面仅监听
`127.0.0.1`，不会访问外网、真实账号或个人文件。

启动测试场：

```bash
max --benchmark
```

在专用浏览器中访问 `http://127.0.0.1:8765/`，手动点击「运行 10 条」或「运行 100 条」。只有该点击
会启动真实浏览器键鼠控制；10 条是固定的难度分层冒烟集，包含 4 easy、3 medium、3 hard 任务，100 条
为完整评测集。随后运行器逐题重置状态、打开任务页面并将自然语言指令交给当前 `.env` 配置的模型。
浏览器窗口应固定大小、缩放、语言和前台状态。Agent 只能用截图和键鼠操作页面，不能获得 DOM 或
评分接口。

任务结束后，运行器读取 `GET /api/state`，按任务成功断言判定严格成功。10 条与 100 条报告分别写入
`artifacts/reports/web-gui-eval-10.json` 与 `artifacts/reports/web-gui-eval-100.json`，并记录请求任务数。
报告必须分别展示任务成功率、
部分完成率、平均耗时、平均工具调用数、工具失败率、无效动作率、违规率和已知 Token 用量；未知
Token 保持为 `null`。基础模型和 LoRA 模型必须使用相同任务集版本、浏览器条件、提示词、温度、
迭代上限和超时。

真实 macOS 验收时使用独立浏览器配置文件，关闭通知和其他应用；只在用户显式启动评测后允许键鼠
控制。每题结束后复位 Web 状态，环境准备失败单独报告，不计入模型任务失败率。
