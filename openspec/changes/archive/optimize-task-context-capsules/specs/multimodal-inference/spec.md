## MODIFIED Requirements

### Requirement: 工具消息中的图像回注
当调用方提供的任务上下文消息携带本地图像引用时，客户端 MUST 把该上下文明确选定的、仍存在的至多
一张图作为 `image_url` 内容部件附加（经现有最长边／最大字节预处理）。同一条消息的文本摘要 MUST
作为文本部件保留。任务上下文未选中的图像引用 MUST NOT 再附加对应 `image_url`，也不得因旧会话中
存在较晚图像而覆盖当前任务的选图。缺失的图像文件 MUST 跳过且不阻止其余部件编码。纯文本 tool 消息
MUST 仍只发送文本。用户消息中的本地图仅在它被任务上下文选为最新有效观察时计入该一张图片限额。

#### Scenario: 当前任务截图进入下一轮 think
- **WHEN** 当前任务的 tool 消息包含文本摘要与被任务上下文选中的存在 PNG 路径
- **THEN** 发给模型的该条消息同时包含文本部件和 `image_url` 部件

#### Scenario: 纯文本工具结果
- **WHEN** 当前任务的 tool 消息是字符串且无被选中的图像引用
- **THEN** 请求中该条消息不含 `image_url` 部件

#### Scenario: 截图文件缺失
- **WHEN** 当前任务选中的图像路径不存在
- **THEN** 客户端仍发送文本摘要，且不因缺图失败

#### Scenario: 旧任务截图不再编码为图像
- **WHEN** 会话历史中存在旧任务截图，当前任务存在另一张被选中的有效截图
- **THEN** 仅当前任务选中的截图带 `image_url`，旧任务截图不带 `image_url`
