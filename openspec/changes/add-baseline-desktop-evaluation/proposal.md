## Why

现有 `max-gui --benchmark` 面向可重置的本地 Web 任务，不能证明 Agent 在真实 macOS 应用、联网信息查询和用户已授权的个人应用中能否完成基础桌面任务。项目收尾需要一套可重复运行、独立截图评审且不把环境/登录问题误计为模型失败的基线评测，供基础模型与 Windows LoRA 模型在同等条件下比较。

## What Changes

- 新增 `max-gui --baseline` 显式入口，顺序执行 5 条版本化基础桌面任务：北京次日天气查询并汇报、终端无副作用命令、计算器 `1+1`、新增带固定验收标签的提醒事项、向微信文件传输助手发送固定测试文本。
- 启动后直接进入第一题；每题调用 Agent 前暂停，要求人类将该题所需窗口前置并按任意键确认；未确认的单题不得启动模型或执行桌面动作。
- 为每项任务配置独立用户提示词、前置环境、动作预算、超时、成功断言和清理说明；不改变既有 `--benchmark` 首页的 10/100 条选择行为。
- 每题完成后启动独立、只读的最终截图评审调用。评审只判断可见证据与任务断言是否匹配，不执行桌面动作，也不得以 Agent 的完成声明替代截图证据。
- 将每题、每次运行和跨运行聚合指标写入本地版本化结果目录；保留模型/环境配置、运行日志引用、截图引用、评审结论和未知 Token 值。
- 提供本地静态可视化报告，展示多次运行中的成功率、耗时、动作数、工具失败率、Token 与终态分布，并可按模型和任务比较。
- 新增基线 JSON 对比报告和受限清理入口：最多读取 5 份批次汇总 JSON 生成 Matplotlib 图表/报告，或只清除基线评测目录内的记录与报告。

## Capabilities

### New Capabilities

- `baseline-desktop-evaluation`: 受用户显式启动、具备安全边界和截图独立评审的 5 条真实 macOS 基线任务评测。

### Modified Capabilities

- `agent-task-evaluation`: 扩展评测结果与报告契约，使其可引用基线桌面任务的逐次指标和跨运行可视化数据，而不改变现有 Web 评测入口语义。

## Impact

- 影响 `src/max_gui/cli.py`、新的基线评测包/任务定义、`AgentRunner` 的评测回调，以及本地结果与报告目录。
- 复用现有会话、运行 JSONL、截图、Token 汇总和桌面安全工具；不新增远程服务或自动化浏览器控制。
- 需补充 CLI、任务加载、执行护栏、评审隔离、指标聚合和报告渲染测试，并在 README/评测文档中说明真实应用的登录、网络、权限和数据写入前提。
