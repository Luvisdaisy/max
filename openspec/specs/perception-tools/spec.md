# Perception Tools Specification

## Purpose

为未来 Agent 编排器提供可注册、只读且可测试的桌面视觉观察能力，使屏幕、文本和 UI 状态以统一结构化结果交付，而不触发桌面输入或持久化敏感图像。

## Requirements

### Requirement: 统一感知工具注册和回执
系统 SHALL 通过唯一工具注册入口公开每个感知工具的稳定名称、结构化输入、结构化输出和失败回执。调用方能够按名称调用已注册工具；未知名称、无效输入和第三方运行时错误 MUST 返回可机器处理的失败回执，而不是触发桌面副作用。

#### Scenario: 调用已注册工具
- **WHEN** 调用方以有效输入通过注册表调用一个已注册的感知工具
- **THEN** 系统返回包含工具名称、成功状态和结构化结果的回执

#### Scenario: 请求未知工具
- **WHEN** 调用方通过注册表请求未注册的工具名称
- **THEN** 系统返回标识未知工具的失败回执，且不调用桌面或视觉库

### Requirement: 内存屏幕观察
系统 SHALL 提供 `observe_screen`，用于捕获全虚拟桌面或调用方指定显示器的当前图像，并返回内存图像、物理像素尺寸、显示器边界和可用 DPI 元数据。该工具 MUST 不写入截图文件，且 MUST 不发送鼠标或键盘输入。

#### Scenario: 捕获指定显示器
- **WHEN** 调用方请求一个可用显示器的截图
- **THEN** 系统返回该显示器的内存图像和与图像对应的物理像素元数据

#### Scenario: 显示器不可用
- **WHEN** 调用方请求不存在或不可捕获的显示器
- **THEN** 系统返回失败回执，且不产生截图文件或桌面输入

### Requirement: 结构化文字识别
系统 SHALL 提供 `recognize_text`，用于识别调用方提供的内存图像并返回文本行、置信度和图像像素坐标边界框。该工具 MUST 不自行捕获屏幕、不保存输入图像，并且 MUST 在本地 OCR 资源不可用时返回明确失败回执而不下载资源。

#### Scenario: 识别内存图像中的文字
- **WHEN** 调用方提供包含可识别文字的内存图像且本地 OCR 资源可用
- **THEN** 系统返回每条已识别文字及其置信度和边界框

#### Scenario: 本地 OCR 资源缺失
- **WHEN** 调用方请求文字识别而本地 OCR 资源不可用
- **THEN** 系统返回说明资源不可用的失败回执，且不发起网络访问或资源下载

### Requirement: UI 与视觉观察增强
系统 SHALL 提供只读的 UI Automation 元素观察、图像预处理与模板匹配，以及按需 Set-of-Mark 图像标注能力。UI Automation 结果 MUST 仅包含观察到的元素属性和边界；视觉处理和标注 MUST 仅处理调用方提供的内存图像。所有这些工具 MUST 不发送桌面输入且不保存输入或输出图像。

#### Scenario: 返回可访问窗口的 UI 元素
- **WHEN** 调用方请求一个可访问目标窗口的 UI 元素
- **THEN** 系统返回元素角色、名称、边界和可用状态的结构化观察结果

#### Scenario: 处理视觉输入
- **WHEN** 调用方提供内存图像并请求预处理、模板匹配或 Set-of-Mark 标注
- **THEN** 系统返回相应的内存处理结果及其坐标或标记元数据，且不写入图像文件

#### Scenario: UI Automation 目标不可访问
- **WHEN** 调用方请求不存在、无权限或无法连接的窗口
- **THEN** 系统返回失败回执，且不尝试激活窗口或发送桌面输入
