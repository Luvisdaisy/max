## 为什么

当前仓库缺少一致、可维护的代码注释基线，使开发者难以快速理解模块边界、关键决策和测试意图。为落实仓库的中文注释规范，需要在不改变现有运行行为的前提下，系统补全文档化说明。

## 变更内容

- 为 `src/max_agent/` 中全部 Python 模块补充或完善中文模块、公开接口及关键实现注释。
- 为 `tests/` 中全部 Python 测试补充中文测试目的、场景与非直观断言的说明。
- 同步更新 `tech-design.md`，记录当前已实现模块的注释文档基线与维护要求。
- 建立可复核的审查与验证步骤，确保注释不改变运行行为且保持与代码一致。

## 能力

### 新增能力

无。本变更不引入用户可观察的产品能力。

### 修改的能力

无。本变更仅补充文档与注释，不改变现有行为契约。

## 影响

- 受影响代码：`src/max_agent/` 下的全部 Python 实现模块，以及 `tests/` 下的全部 Python 测试模块。
- 受影响文档：根目录 `tech-design.md` 和本变更的 OpenSpec 工件。
- 不改变公开命令、API、依赖、配置格式或运行时行为。
