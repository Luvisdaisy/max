# Web GUI Agent 评测场

`web-gui-v1` 由 20 个工作流模板各展开 5 次，共 100 条任务。页面仅监听
`127.0.0.1`，不会访问外网、真实账号或个人文件。

启动测试场：

```bash
uv run python scripts/eval_agent.py --port 8765
```

评测前在专用浏览器窗口打开 `http://127.0.0.1:8765/form`、`/files` 或 `/settings`，并固定窗口
大小、缩放、语言和前台状态。运行器先调用 `POST /api/reset` 重置任务，再将任务自然语言指令交给
Agent；Agent 只能用截图和键鼠操作页面，不能获得 DOM 或评分接口。

任务结束后，运行器读取 `GET /api/state`，按任务成功断言判定严格成功。报告必须分别展示任务成功率、
部分完成率、平均耗时、平均工具调用数、工具失败率、无效动作率、违规率和已知 Token 用量；未知
Token 保持为 `null`。基础模型和 LoRA 模型必须使用相同任务集版本、浏览器条件、提示词、温度、
迭代上限和超时。

真实 macOS 验收时使用独立浏览器配置文件，关闭通知和其他应用；只在用户显式启动评测后允许键鼠
控制。每题结束后复位 Web 状态，环境准备失败单独报告，不计入模型任务失败率。
